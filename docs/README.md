## 🧭 Sobre o Projeto

O **Geo-Explorer** é um assistente educacional fictício que ajuda desenvolvedores a:
- Explorar **trilhas de aprendizagem** organizadas por tecnologia e nível
- Gerar **desafios de código** práticos e contextualizados
- Emitir **certificados fictícios** de conclusão de trilha

---

## 🛠️ Comandos Disponíveis

### 1. `trilha <tecnologia> <nível>`
Retorna um plano de estudos completo com módulos, objetivos e projeto final.

**Exemplo:**
```
trilha react intermediário
trilha python iniciante
trilha java avançado
```

---

### 2. `desafio <tecnologia> <nível>`
Gera um desafio de código com enunciado, requisitos e critérios de aceitação.

**Exemplo:**
```
desafio javascript avançado
desafio node.js intermediário
```

---

### 3. `certificado <nome> <trilha>`
Cria um certificado fictício de conclusão com código único e badges.

**Exemplo:**
```
certificado Érica "React Intermediário"
certificado João "Python Iniciante"
```
